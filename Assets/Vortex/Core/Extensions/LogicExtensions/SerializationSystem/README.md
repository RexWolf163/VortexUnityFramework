# `SerializeController` — Платформонезависимый сериализатор Vortex

**Версия:** 1.0  
**Платформа:** .NET Standard 2.1+ (независимо от Unity)  
**Уровень архитектуры:** 1 (`Vortex.Core.Extensions.LogicExtensions`)  

---

## Назначение

`SerializeController` — универсальный сериализатор. Преобразует объекты в строковое представление в формате JSON и обратно без зависимости от внешних библиотек (`System.Text.Json`, `Newtonsoft.Json`)

---

## Контракт

### Вход
- Любой объект с публичными свойствами, имеющими геттер и любой сеттер (`public`, `protected`, `private`).
- Поддерживаемые типы:
  - Простые типы (`int`, `float`, `string`, `bool`, `DateTime`, `enum`, `Nullable<T>`)
  - Массивы и списки (`IList`, `T[]`)
  - Словари (`IDictionary<TKey, TValue>`), где ключ — простой тип или `Type`

### Выход
- Строка в текстовом формате JSON.
- При десериализации — экземпляр объекта заданного типа, восстановленный из строки.

### Гарантии
- **Типобезопасность**: десериализация возможна только в совместимый тип (`IsAssignableFrom`).
- **Целостность ссылок**: циклические ссылки разрываются на этапе сериализации и не сохраняются.
- **Нейтральность**: компонент работает на базе .Net и не требует внешних библиотек.

### Ограничения
- Не поддерживает поля — только свойства (для упрощения контроля сохраняемой модели разработчиком).
- Не поддерживает сложные ключи в словарях — только простые типы или `Type`.
- Циклические ссылки игнорируются — не сохраняются и не восстанавливаются.

---

## Поведение в граничных случаях

- **Несовместимый тип при десериализации**: вызывает логирование ошибки и возврат `null`/`default`.
- **Отсутствие сеттера у свойства**: пропускается при сериализации и десериализации.
- **Неподдерживаемый тип в словаре**: логируется ошибка, возвращается `null`.

---

## Примеры использования

### Сериализация
```csharp
var myObject = new MyData { Name = "Test", Value = 42 };
string serialized = myObject.SerializeProperties();
```

### Десериализация
```csharp
MyData restored = serialized.DeserializeProperties<MyData>();
```

> ⚠️ Десериализация работает только если целевой тип совместим с типом, сохранённым в строке. Проверка выполняется через `IsAssignableFrom`.

# Vortex Database System — Ядро

**Версия:** 1.0  
**Платформа:** .NET Standard 2.1+ (независимо от Unity)  
**Зависимости:**  
- Vortex Core (`SystemController`, `ISaveable`, `ILogicExtension` и др.)

---

## Назначение

Ядро системы базы данных реализует платформо-независимую модель хранения и доступа к данным приложения. Оно управляет двумя категориями записей:

- **Singleton-записи** — глобальные объекты, существующие в единственном экземпляре.
- **MultiInstance-записи** — шаблоны, на основе которых создаются временные копии.

Загрузка данных делегирована внешнему драйверу. Ядро не содержит логики чтения источников данных.

Интеграция с системой сохранения ограничена сериализацией состояния только Singleton-записей. MultiInstance-записи **не сохраняются**, поскольку не обладают глобальным состоянием; логика сохранения и восстановления их копий **целиком возлагается на систему, которая запросила эти копии**.

## Компоненты

### `Database`
Центральный контроллер, предоставляющий следующие статические методы:

- `GetRecord<T>(string guid)` — возвращает ссылку на существующую Singleton-запись.
- `GetNewRecord<T>(string guid)` — запрашивает у драйвера новую копию MultiInstance-записи по её GUID.
- `GetRecords<T>()` — возвращает все Singleton-записи заданного типа.
- `TestRecord(string guid)` — проверяет наличие записи с указанным GUID (используется в редакторе).

Контроллер автоматически регистрируется в `SaveController` при подключении драйвера и участвует в процессе сохранения/загрузки только для Singleton-записей.

### `Record`
Абстрактный класс, наследуемый от `SystemModel`. Обязательно реализует:

- `string GetDataForSave()` — возвращает строковое представление состояния для сериализации.
- `void LoadFromSaveData(string data)` — восстанавливает состояние из строки.

Содержит метаданные: `GuidPreset`, `Name`, `Description`.

## Жизненный цикл

1. **Инициализация**  
   Вызывается `Database.SetDriver(IDriver)`. Драйвер получает ссылки на внутренние коллекции и заполняет их.

2. **Доступ к данным**  
   Приложение использует статические методы `Database.GetRecord<T>()` или `Database.GetNewRecord<T>()`.

3. **Сохранение**  
   При вызове `SaveController.Save()`:
   - Для каждой записи в `_singletonRecords` вызывается `GetDataForSave()`.
   - Результат сохраняется в словарь `<GUID, данные>` под ключом `"Database"`.

4. **Восстановление**  
   При вызове `SaveController.Load()`:
   - Извлекаются данные по ключу `"Database"`.
   - Для каждой записи, присутствующей одновременно в сохранении и в `_singletonRecords`, вызывается `LoadFromSaveData()`.

---

## Ограничения

- **MultiInstance-записи не участвуют в сохранении**, так как не имеют глобального состояния.
- **Отсутствует механизм подписки на изменения** состояния записей.
- **Статическая архитектура** не допускает одновременного использования нескольких изолированных экземпляров базы данных в одном приложении.
- **Нет встроенной валидации дубликатов** при заполнении `_singletonRecords`: повторная запись с тем же GUID перезаписывает предыдущую без предупреждения.

---

> Примечание: Ядро требует подключения драйвера для функционирования. Рекомендуется использовать официальный Unity-адаптер (`Vortex.Unity.DatabaseSystem`).

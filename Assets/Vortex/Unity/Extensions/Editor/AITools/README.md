# AI Context Creator  
**Инструмент агрегации исходного кода и документации для внешнего анализа**

## Назначение

Инструмент `AIContextCreator` формирует текстовые артефакты, содержащие полное содержимое всех файлов с расширениями `.cs` и `.md`, расположенных в указанной директории проекта Unity и её подкаталогах. Артефакты предназначены для передачи во внешние системы анализа, включая языковые модели (LLM), и не модифицируют исходные данные.

## Функциональная спецификация

1. **Инициация**  
   Запуск осуществляется через контекстное меню редактора Unity: при выделении одной директории в Project Window доступен пункт  
   `Assets/Vortex/Debug/Create Context for AI`.

2. **Обработка файлов**  
   - Сканируются все файлы, соответствующие шаблонам `*.cs` и `*.md`, с рекурсивным обходом подкаталогов.
   - Для каждого файла сохраняется:
     - его относительный путь от корня `Assets`,
     - полное содержимое в кодировке UTF-8 без изменений,
     - визуальный разделитель вида `// ============================================================`.

3. **Формат вывода**  
   Каждый тип файлов записывается в отдельный текстовый артефакт:
   - `{FolderName}_{Timestamp}.txt` — для C#-файлов,
   - `{FolderName}_MD_{Timestamp}.txt` — для Markdown-файлов,  
   где `Timestamp` — значение `DateTime.UtcNow.ToFileTimeUtc()`.

4. **Размещение артефактов**  
   Выходные файлы сохраняются в каталог, расположенный на два уровня выше пути `Application.dataPath` (т.е. вне дерева проекта Unity). Это исключает их попадание в систему контроля версий или сборку.

5. **Производительность**  
   Обработка выполняется асинхронно: после каждых 100 обработанных файлов вызывается `Task.Yield()`, что предотвращает блокировку основного потока редактора.

6. **Ограничения доступа**  
   Пункт меню недоступен при:
   - отсутствии выделенного объекта,
   - выделении более одного объекта,
   - выборе файла вместо директории.

## Технические ограничения

- Не предназначен для использования в рантайме.
- Корневая папка проекта должна называться Assets.
